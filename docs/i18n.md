# Đa ngôn ngữ (i18n)

Dự án hỗ trợ **tiếng Anh (`en`)** và **tiếng Việt (`vi`)** qua
[`react-i18next`](https://react.i18next.com/).

## Cấu hình — `src/Assets/lang/i18n.js`

Toàn bộ chuỗi dịch nằm trong **hai object phẳng** `en` và `vi` trong cùng một
file. Đây là single source of truth — không có file JSON tách riêng.

```js
i18n.use(initReactI18next).init({
  resources: { en: { translation: en }, vi: { translation: vi } },
  lng: localStorage.getItem('language') || 'en',
  fallbackLng: 'en',
  keySeparator: false,     // 'stack.devops.title' là MỘT key phẳng
  nsSeparator: false,      // dấu ':' trong chuỗi không bị hiểu là namespace
  interpolation: { escapeValue: false },
  react: { useSuspense: false, /* ... */ },
})
```

- **`keySeparator: false` là bắt buộc.** Key trong dự án là chuỗi phẳng có dấu
  chấm (`hero.cta.resume`). Mặc định i18next coi dấu `.` là đường dẫn lồng nhau
  và sẽ đi tìm `hero → cta → resume`. Tắt đi để nó tra đúng key nguyên văn.
- Ngôn ngữ được **ghi nhớ trong `localStorage['language']`** bởi `LanguagePicker`.
- `escapeValue: false` cho phép một số chuỗi chứa HTML.

## Quy ước đặt key

Key phẳng, đặt tên theo section, phân tách bằng dấu chấm:

| Tiền tố | Dùng cho |
|---------|----------|
| `profile.*` | tên, vai trò, địa điểm, tagline |
| `nav.*`, `common.*` | điều hướng và nhãn dùng chung |
| `hero.*`, `stats.*`, `typed.*` | khối hero trang chủ |
| `home.*` | các section còn lại của trang chủ |
| `about.*` | trang About |
| `exp.*`, `edu.*`, `cert.*` | mục trong dòng thời gian / học vấn / chứng chỉ |
| `stack.*` | trang Stack (nhóm, chú giải, mức độ) |
| `projects.*`, `demo.*`, `proj.*`, `links.*` | trang Projects |
| `resume.*` | trang Resume |
| `contact.*`, `footer.*` | liên hệ và chân trang |

Dữ liệu trong `src/data/` **không chứa câu chữ**, chỉ giữ key (trường hậu tố
`Key`) và để component gọi `t(key)` — xem [data-layer.md](./data-layer.md).

## Cách dùng trong component

```jsx
import { useTranslation } from "react-i18next";

function MyComponent() {
  const { t } = useTranslation();
  return <h1>{t('nav.home')}</h1>;
}
```

Đổi ngôn ngữ: đã có sẵn trong `LanguagePicker`
(`i18n.changeLanguage(lang)` + `localStorage.setItem('language', lang)`).

## Thêm / sửa chuỗi dịch

1. Mở `src/Assets/lang/i18n.js`.
2. **Thêm key vào CẢ HAI object** `en` và `vi`.
3. Dùng `t('your.key')` trong JSX, hoặc trỏ tới nó từ `src/data/` qua trường
   `*Key`.
4. Chạy kiểm tra:

```bash
npm run check:i18n
```

## Script `scripts/check-i18n.mjs`

Kiểm tra tĩnh (không cần chạy app), báo lỗi và trả exit code khác 0 khi:

- key được tham chiếu trong `src/` nhưng **thiếu ở `en` hoặc `vi`**;
- key có ở `en` mà không có ở `vi` (và ngược lại);
- key khai báo trong i18n mà **không nơi nào dùng** (key chết).

Script quét mọi file `.js`/`.jsx` trong `src/` (bỏ qua `src/features/`) và bắt cả
key nằm trong mảng dữ liệu (`bulletKeys: ['exp.nexusti.b1', …]`), không chỉ lời
gọi `t()`. Các key ghép bằng template literal lúc render (vd
`` t(`stack.level.${lvl}`) ``) được liệt kê thủ công ở cuối script — **thêm mẫu
key động mới thì nhớ bổ sung vào đó**.

## Chuỗi chứa HTML

Một số key mô tả demo (`demo.*.body`) chứa `<br/>`, `<b>`. Chúng được render bằng
`dangerouslySetInnerHTML` trong `Projects.jsx`:

```jsx
<div className="pf-demo-summary"
     dangerouslySetInnerHTML={{ __html: t(current.bodyKey) }} />
```

Nguồn là file dịch của chính dự án (không phải input người dùng). Khi sửa các key
này, giữ nguyên thẻ HTML hợp lệ.

## Lưu ý

- Đừng hardcode chuỗi tiếng Anh/Việt trực tiếp trong JSX — luôn đi qua `t()`.
- **Danh từ riêng không dịch**: tên công nghệ (`Java 21`, `Kubernetes`), tên công
  ty (`Nexusti JSC`), email, số điện thoại, URL, mốc thời gian. Chúng nằm thẳng
  trong `src/data/` và hiển thị nguyên văn ở cả hai ngôn ngữ.
